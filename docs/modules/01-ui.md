# 01 · Figma 界面模块

## 职责与文件

- `apps/web/src/app/page.tsx`：页面编排、请求状态、草稿与当前会话。
- `app/styles.css`：设计 token 与响应式布局；未引入其他 UI 库。
- `components/Shell.tsx`：240px侧栏、历史、账号菜单、移动导航。
- `components/ui.tsx`：原始图标、按钮、开关、提示。
- `features/tasks/TaskSelector.tsx`：三个任务；`features/learning/*`：对话、输入、结束回顾。
- `features/consent/ConsentPanel.tsx`：独立授权设置。

## 输入输出与修改方法

UI 只通过 `lib/api.ts` 调用同域 `/api`。`LearningSession` 类型位于 `lib/types.ts`，由后端版本号控制。本轮没有路由复杂度，页面状态在 `page.tsx` 中；刷新后回到任务列表，可从真实历史进入会话。

界面文案在 `src/i18n/zh-CN.ts` 与 `en.ts` 中同步维护，组件通过翻译函数读取，不新增硬编码可见文本；改视觉优先 token 与 CSS，不修改业务状态。新增页面应新增 feature 组件，不把算法写进 page。不要给无法调用的功能添加可点击假按钮。

草稿只在内存，不进 localStorage 或行为遥测。网络失败保留草稿；切换会话或刷新丢弃。历史栏只展示真实会话，不渲染 Figma 示例历史。

## 验证与限制

运行 `npm run typecheck` 与 `npm run build`。在1440×960、1024×768、390×844和360×800检查溢出、输入可用、菜单与摄像头不遮挡。首次缺少真实学习内容时不会显示 Figma 样例对话，这是诚实数据状态。

本轮没有语音输入与研究表单。摄像头支持悬浮拖动，移动端输入聚焦收起预览；使用原设计配色、图标与尺寸，拖动细节见模块06。


## AI 接口配置入口（补充）

用户追加要求在页面填写第三方 API，新增 `features/settings/AIConnectionSettings.tsx` 与独立路由 `/settings/ai`，复用原设计 token、704px阅读列、表单与按钮风格。该管理表单没有对应的原始 Figma 画板。账户菜单保留 AI 接口设置、隐私与数据及活动会话的结束入口，“学习设置”菜单项已删除；AI 配置仍可从未接入提示打开。页头没有单独设置按钮。通过 Home 内视图打开时保留草稿与当前会话；独立路由的“返回学习”回到首页。

## 首页文案精简

任务选择页按用户标注移除标题上方的引导小字和底部节奏说明，同时移除两者的手机版本。Shell在没有当前任务时不再渲染页头“学习助手”，保留面包屑容器占位以维持访客菜单靠右；学习中的任务面包屑仍显示。复用原有桌面/手机留白和断点，删除元素后由现有flex间距自然收拢，不补空白占位。

## 自由对话更新

课程顶部显示课题与当前焦点，不显示固定步数。移除依赖ready的“继续本步”门槛，保留随时可用的提示、示范、继续探索、换例子与纠正。进入空会话且已配置API时仅自动请求一次开场；失败后可明确重试或直接输入。未配置时显示连接入口，不塞入题库消息。

主动卡只展示服务器实际生成的episode.text，无文字时不显示。正在思考的保护状态用中性产品提示呈现。结束回顾统计练习证据，不把探索自由对话包装成六步完成度。复用既有响应式按钮换行、阅读列和断点，无新增断点或设计token。

## 摄像头关闭入口

关闭摄像头后原位置保留带图标的“开启摄像头”长方形卡片，展开、收起和关闭状态复用同一可拖动悬浮层。44px最小点击高度，浅绿底与现有accent色，不增加断点。重新开启恢复展开画面；未满足授权条件时进入既有学习设置。

## 悬浮拖动修订

按用户标注将摄像头移出lesson-top的行内布局，课程正文不再为摄像头预留高度。保留既有桌面/平板/手机宽度与断点，增加点状手柄；默认位置由fixed定位提供，用户拖动后用坐标定位。窗口尺寸或卡片状态改变时保持可见；手机支持触摸手柄拖动，关闭状态也可移动。

## 视觉准备与学习状态颜色

摄像头卡片先显示真实Worker加载阶段、不定进度和等待时间，再显示后端原引擎的个人基线校准：有效采样/60秒与真实进度。无效画面暂停累计，断线/基线不足给出重试；收起仍显示紧凑状态。不是前端倒计时模拟完成。

疲劳/负荷提醒采用琥珀色（底#fff7e7、文字#805b20、边框#ead8b5）和“!”标识，保留“根据你的反馈”来源说明，按最新用户标注放在实时画面右下角，来源放入悬停说明，不再占独立横幅。沿用原宽度和767px手机断点；手机字号10px并自动换行。状态变化通过原ResizeObserver保持悬浮窗可见。颜色仅用于这类提醒，不改原Figma主色。

视觉提醒区分明确自述与visual_heuristic，后者使用“可能疲劳/负荷可能偏高”和“视觉信号 · 待你确认”，AI解释仅在真实模型返回时显示。沿用既有琥珀色token、摄像头宽度和拖动边界，不新增断点；接口见模块13。

## 多语言界面（2026-11-03）

- `src/i18n/index.ts` 使用 i18next、react-i18next 与 i18next-browser-languagedetector，当前支持 `zh-CN`、`en`，默认中文。检测顺序为显式保存的偏好、浏览器语言、中文回退；`zh-*` 与 `en-*` 分别归一到对应语言。localStorage 键为 `study.interface-language`，浏览器检测不自动写入偏好，只有用户通过 `selectLanguage()` 选择时才显式持久化；存储被拒绝时仍允许本次切换。
- `zh-CN.ts` 是中文基准资源，`en.ts` 通过 `TranslationShape<typeof zhCN>` 约束中英文 key 结构一致，插值变量与复数使用 i18next 格式。界面组件通过 `useTranslation()` 读取资源；新增语言时增加同形资源、语言代码和选择项，不修改学习协议或模型提示词。
- `RootLayout` 保持服务端组件，直接嵌套带有 `'use client'` 边界的 `I18nProvider`，不需要也不应把整个根布局改为客户端组件。布局不再硬编码title或description；Provider挂载后检测语言，写入 `<html lang>` 与title，并在description不存在时创建meta、在语言变化时继续同步。原始SSR HTML因此不再输出可能不匹配的元数据，代价是水合前title/description为空；可见正文仍采用中文首帧、挂载后切换的防hydration mismatch策略。
- `components/LanguageSwitcher.tsx` 是主 Shell 与独立 `/settings/ai` 页面共用的下拉选择器，沿用现有控件、焦点和响应式样式。`app/styles.css` 同时适配英文长文本、面包屑省略和移动任务卡自动高度，不改变既有断点与 Figma 视觉基线。
- `course.ts` 只按稳定课程 ID、公开标题和 `title_version` 本地化课程元数据及自动历史名称；用户自定义历史名保持原文。`errors.ts` 在显示边界把已知中文规范错误映射到资源 key，未知错误保留原文。用户输入、模型回复、episode 正文、自述与证据引文不做伪翻译。摄像头组件保存稳定状态 key，交给学习状态机的规范设备消息仍为中文，语言切换不会重新启动采集。

国际化资源、实时切换、持久化、异常回退和摄像头生命周期均有前端回归测试；真实 Chrome 的页面与视口验收范围及未验证矩阵见模块10和 `docs/VERIFICATION.md`。
