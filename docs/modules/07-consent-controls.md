# 07 · 分项同意与用户控制

## 职责与位置

`ConsentPanel.tsx` 提供support/camera两个独立开关，首次关闭。`contracts.py` 定义Consent/Control；`learning.py`执行转换，`main.py`负责版本与取消。没有声学或转写授权开关，因为本轮没有这些服务。

开启camera要求support也开启。关闭support会撤销camera。系统权限在确认开启并进入校准准备页后由真实 getUserMedia 请求，设置开关选择本身不偷偷采集。consent_log保存每次应用层设置与时间，不等于浏览器权限凭证。

## 控制语义

| 控制 | 效果 |
|---|---|
| end | 结束会话、停支持、关camera、取消生成；重复操作不改变结果 |
| pause | 暂停主动支持并关camera；普通文字问答仍可用 |
| resume | 恢复已同意的支持，camera保持关闭，需要重新选择 |
| consent | 设置support/camera，撤权优先于旧版本回复 |
| think | 保护当前题，取消旧建议 |
| reject | 关闭当前事件，本题不再自动插卡 |
| correct | 先保存纠正并清除旧状态、保护当前讨论；真实AI动态承接，失败仍保留纠正 |

页面退出学习视图会暂停支持，避免离开时继续采集或生成。结束、暂停、撤权接受旧client版本，不能因网络延迟拒绝用户关闭。其他动作发生题目版本变化时409，前端刷新状态而非重复执行到错误题目。

## 修改方式与验证

加新的采集用途必须新增独立同意字段、UI告知、停采路径及日志，不可借用camera同意。扩展生命周期应列出每一条控制与pending/episode的关系。

测试 `test_priority_controls_accept_stale_version_and_end_is_idempotent`、`test_pause_keeps_normal_chat_available`、`test_end_discards_inflight_reply_even_with_stale_client`。真机检查硬件指示灯与track状态仍必要。

页面隐私说明准确区分本地记录与第三方保留：本地保留至删除；服务商日志/训练开关需接入者核实。未承诺零留存，也未设置未经实现的30天自动清理。

## 开始页按钮

开始页仅保留“确认开始”和“返回”。确认开始提交当前两个开关的真实选择；两个开关关闭时即为文字学习，因此不再提供额外的“仅使用文字”快捷按钮。学习中的设置页仍使用“保存并继续”。未连接 AI 的提示卡使用白色填充、绿色边框的“配置 AI 接口”按钮，复用现有 accent/bg token 和44px按钮高度；桌面与手机统一呈现，无新增断点。

## 文字意图与生成控制

在真实模型连接时，明确的暂停/结束/拒绝文字请求也可转为实际控制；仍在思考则保护当前题并由模型简短承接，不继续追问。文字意图识别有模型延迟，页面按钮始终可即时取消。普通纠正在本轮状态策略中优先，不等待30秒。暂停和恢复清空连续错误统计，不复活旧窗口。

## 摄像头快速重新开启

学习页面关闭摄像头后保留“开启摄像头”入口。已同意support的会话可由该显式点击重新提交camera授权；未同意support时进入设置选择，不静默开启主动支持。重新开启仍遵守原有浏览器权限、前台和active条件。

摄像头关闭时先在组件内立即停采并折叠，onClose异步保存授权。请求未完成时禁用重新开启，失败仍保持本地关闭，避免网络延迟让摄像头继续工作或自动恢复。

疲劳/信息负荷提醒要求主动支持已开启，自述与视觉候选分别标注来源，视觉使用暂定措辞。暂停、结束、撤权会断开WS并清除run，明确自述纠正抑制对应视觉提醒。关闭与后台停采同时清除本地加载阶段和后端校准；重新开启创建新run。开启摄像头后，需先完成有效校准才进入 AI 对话；校准中可显式关闭摄像头转为文字学习。准备阶段同样保留优先控制，详见模块16。

详细数据说明位于隐私页：视频和关键点留在浏览器，派生特征到本机后端，最新状态摘要给配置的AI服务。start与每次WS数据均重新检查camera/support授权；过期ticket和旧run不能在撤权后恢复。该功能沿用用户明确要求的视觉辅助学习用途，不扩大为身份识别或视频上传。

2026-10-30按用户页面标注，开始页标题改为“监测方式与 API”，移除重复的同意说明块与提交数据脚注。开关和后端同意检查保持原行为；该次删文案不改变采集或第三方数据用途。

## 暂离不再等于撤销（2026-11-09）

站内设置/隐私/历史导航使用suspend，停止设备和后台生成但不把camera同意改为false。后台同样停采，未手动关闭且授权有效时回前台恢复；显式关闭保持关闭。临时参考与新run/新ticket分开管理：只有当前合法授权可启动复核，结束/撤销support/删除清除参考，详见模块18。
